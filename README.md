# BIS568 Final Project: AKI Early Prediction

## Overview

This repository now contains an AKI early-prediction pipeline built on MIMIC-IV 2.2.
The current workflow is organized around:

- staged SQL extraction in BigQuery
- a Colab entry script for materializing the AKI cohort
- a cleaning notebook for leakage-aware preprocessing
- a baseline modeling notebook using subject-level splits

The MVP task definition is:

- adult ICU patients
- first ICU stay per patient
- 6-hour observation window
- 24-hour prediction horizon
- one row per `stay_id`
- target: `future_aki_24h`

## Repository Structure

### Extraction

- [data_fetch_aki.py](data_fetch_aki.py): Main Google Colab entrypoint. Authenticates with BigQuery, runs SQL stages in order, prints row counts, optionally runs sanity checks, and exports the final raw AKI cohort CSV.
- [sql/](sql): Modular SQL stages for cohort definition, KDIGO staging, AKI onset, prediction anchors, feature extraction, final dataset assembly, and sanity checks.
- [mimiciv_tables.md](mimiciv_tables.md): Local reference listing the MIMIC-IV 2.2 table paths available in the current environment.

### Notebooks

- [notebook/aki_data_cleaning.ipynb](notebook/aki_data_cleaning.ipynb): Loads the raw AKI cohort CSV, reviews missingness and leakage-sensitive columns, and exports a cleaned dataset.
- [notebook/aki_model_dev.ipynb](notebook/aki_model_dev.ipynb): Loads the cleaned dataset, performs a subject-level split by `subject_id`, and trains baseline models.

### Outputs

- [notebook/outputs/mimic_aki_cohort_raw.csv](notebook/outputs/mimic_aki_cohort_raw.csv): Raw one-row-per-stay AKI cohort exported from BigQuery.
- [notebook/outputs/mimic_aki_cohort_cleaned.csv](notebook/outputs/mimic_aki_cohort_cleaned.csv): Cleaned dataset generated by the cleaning notebook.

### Data Doc

- [mimic_aki_cohort_cleaned_context.md](mimic_aki_cohort_cleaned_context.md): Data context for `notebook/outputs/mimic_aki_cohort_cleaned.csv`, covering dataset shape, prediction task, target distribution, and column-level descriptions for downstream modeling.
